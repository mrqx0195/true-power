# 真正的力量（True POWER）

一个[**拔刀剑：重锋**](https://www.mcmod.cn/class/14899.html "拔刀剑：重锋")的附属模组，大幅修改了其战斗相关内容。

# 简介

显而易见的是，拔刀剑：重锋的战斗系统大规模地复刻了《鬼泣5》中维吉尔的战斗系统。
但它仍有诸多令人不满意的地方，包括奇怪的手感以及一言难尽的按键判定。
本模组大规模替换、重写了重锋的战斗系统，以追求更“鬼泣”的战斗，即——真正的力量。
*建议配合[**越肩视角重制**](https://www.mcmod.cn/class/3305.html "越肩视角重制")游玩。*

# 评价相关

* ⚙ *（可配置所需评价）* 评价较高时自动进入[**魔化**](https://www.mcmod.cn/item/865064.html "魔化")状态（默认需要 SSS 评价）；
* ⚙ *（可配置具体的评分值）* 降低攻击时获得的评分；
* ⚙ *（可配置具体的评分值）* 击杀敌人时获得额外的暂存评价，如果完成收刀则会将其转换为真正的评价分；
* 通过造成伤害，每[**游戏刻**](https://www.mcmod.cn/item/211558.html "游戏刻")仅能提高一次评价；
* 评价较高时，使用拔刀剑将会获得额外的伤害增益；如果评价过低，则会获得减益；
* 扩大了 S/SS/SSS 的评价分数区间，但现在评价自然回落将会使评价等级降低。

## 剑技相关

* ⚙ *（可开关）* 使用部分剑技时无法移动（但部分情况下可以用跳跃、瞬步系列能力强行取消）（v1.2.0以后可通过数据包修改，但仅支持模组内置和KubeJS提供的数据）；
* 重复的剑技在一段时间内将无法获得评价；
* ⚙ *（仅伤害可配置）* 潜行 + （后 → 前） + 点击左/右键点击*（判定与《鬼泣5》相近）* 将会释放**虚无刀界**（注意：该虚无刀界与作为
  SA 的虚无刀界不同！）；
* 后前释放的虚无刀界在处于魔化状态时具有两次伤害，并在收刀时拉近范围内的敌人；
* ⚙ *（目标数可配置）* 处于[魔化](https://www.mcmod.cn/item/865064.html "魔化")状态时，作为 SA 的**次元斩**能够额外攻击附近的两个目标；
* 连击 C 的最后一刀会附加一枚幻影剑，这枚幻影剑在收刀时会爆炸、将目标挑飞（魔化状态下提升为 6 枚）；
* [魔化](https://www.mcmod.cn/item/865064.html "魔化")状态下，疾走居合在结束时会为所有命中的敌人附加一枚幻影剑，这枚幻影剑在收刀时会爆炸、将目标挑飞；
* 大部分剑技的伤害进行了调整，部分剑技额外进行了手感上的优化；
* ⚙ *（v1.2.0以后）（可开关，默认开启）* 新增气绝值系统，开启时同时禁用原版拔刀剑的眩晕系统：
    * 所有生物拥有独立的气绝值积累槽。受到特定连招攻击时会积累气绝值，积累满后进入**气绝状态**
      ：头部冒出电火花粒子、无法进行大部分行动且丢失目标，正常持续约 6 秒，结束后恢复所有气绝值；
    * 所有生物拥有属性 `truepower:stun_resistance` 属性（默认 1.0），生物最大气绝值为该属性与生物基础生命值的乘积；
    * 魔化状态的生物攻击积累气绝值效率提升 **20%**；受到气绝值减少 **25%**；
    * 部分招式会直接触发短暂的气绝效果。
* ⚙ *（v1.2.0以后）（可配置）* 现在手持拔刀剑时，自身与其他实体的接触变为固体碰撞，在空中及部分招式中变为无视碰撞。

## 按键相关

* [**瞬步上行**](https://www.mcmod.cn/item/863593.html "瞬步上行")按键改为：不按方向键时单点
  [**特殊移动**](https://www.mcmod.cn/item/863321.html "特殊移动")键；
* [**暴雨幻剑阵**](https://www.mcmod.cn/item/864581.html "暴雨幻剑阵")的按键改为：潜行 + （后 → 前） + 点击
  [**召唤幻影剑**](https://www.mcmod.cn/item/863322.html "召唤幻影剑")键 *（判定与《鬼泣5》相近）*；
* [**瞬步退行**](https://www.mcmod.cn/item/863664.html "瞬步退行")的按键改为：潜行 + （后 → 前） + 点击
  [**特殊移动**](https://www.mcmod.cn/item/863321.html "特殊移动")键（判定与《鬼泣5》相近）；
    * *（v1.2.0以后）* 如果保持按住**特殊移动**，将会自动连续触发瞬移。
* *（v1.2.0以后）* 所有 后 → 前 按键的输入窗口大幅扩大；
* *（v1.2.0以后）* 锁定时，通过鼠标滚轮可以切换锁定目标。

## 幻影剑相关

* ⚙ *（v1.1.7以后）（可开关，可调整倍率）* 幻影剑的伤害大幅降低，但现在会受玩家面板攻击力影响。

## 其他

* 处于[魔化](https://www.mcmod.cn/item/865064.html "魔化")状态时，使用拔刀剑将会获得额外的伤害增益；
* 手持拔刀剑时，玩家无法进入潜行/游泳状态；
* 使用剑技期间，玩家将无法切换手持物品（防止某些问题）；
* ⚙ *（v1.2.0以后改为默认开启）（可开关）* 使用部分剑技时将会向前移动（就像在《鬼泣5》中那样）。

## 客户端配置

* ⚙ *（v1.1.7以后）（可开关，可调整锁定值）* 手持拔刀剑时，视场角（FOV）将会锁定为固定值；
* ⚙ *（可调整倍率）* 处于锁定状态时，视角的移动速度提升至 4 倍。

# 联动特性

## *（v1.2.0以后）* 越肩视角重制

*（以下均为越肩视角下的特殊行为）*

* 持有拔刀剑时，禁用大部分情况下的相机自动旋转；
* 对移动输入进行了修改，对于剑技的按键判断，输入将会按照玩家实体朝向旋转（就像在《鬼泣5》中那样）（例如，玩家面向右方，此时需要按
  向右移动 键才能释放疾走居合）（不影响实际玩家移动）；
* 锁定时优先选择十字准星指向的实体（而非玩家实体面向的实体）。
